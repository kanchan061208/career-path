# 🎓 Student Skill & Career Recommendation System

A web-based application that helps students explore suitable career paths based on their skills, interests, and academic background.

## 📌 About the Project

The Student Skill & Career Recommendation System is designed to guide students in identifying career opportunities that match their abilities and interests.

Students can enter their details, select their skills, complete an assessment, and receive career recommendations.

## ✨ Features

- Student information form
- Skill and interest assessment
- Personalized career recommendations
- Multiple career options
- Student assessment records
- Simple and user-friendly interface
- SQLite database for storing records

## 🛠️ Technologies Used

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd student-skill-career-recommendation
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in browser

```text
http://127.0.0.1:5000
```
